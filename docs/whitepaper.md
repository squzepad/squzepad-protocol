# Squzepad Whitepaper

## Vision

Most token launches stand alone. Squzepad treats a launch as the start of a family: every new token is tied to a parent, and each release can lift the next. The aim is a Solana ecosystem where related projects stay connected instead of scattering.

## Mission

Give token creators a simple way to build beyond a first token: seed a parent, attach children beneath it, and share upside along the branch, without ever taking custody of anyone's funds.

## How it works

1. **Seed a parent.** A creator starts with one token on pump.fun. It is the root of a tree.
2. **Attach children.** Builders open new tokens beneath an existing one. Each child records its parent on-chain.
3. **Share the upside.** Creator fees are divided between Squzepad and the parent. A portion of platform proceeds is set aside for the $SQUZEPAD token and locked, following the project's published mechanics.
